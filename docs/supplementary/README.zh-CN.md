# 补充视频与交互展示

本目录配套论文 *Observation feedback can conceal competing dynamics*，提供8部补充视频与5个交互查看器。

[打开在线展示](https://brianzhu1999.github.io/PCE-APCE/supplementary/)

## 视频与论文对应关系

| 编号 | 内容 | 论文位置 |
| --- | --- | --- |
| 1 | 不确定波动、弹簧振动与热传导 | 扩展数据图2 |
| 2 | 五个非线性动力学系统 | 图2 |
| 3 | Lorenz–96 | 图3a–f |
| 4 | Kuramoto–Sivashinsky | 图3g–l |
| 5 | Kolmogorov流 | 图3m–p |
| 6 | 实测圆柱尾流 | 图4 |
| 7 | MeshRIR三维声场 | 扩展数据图3 |
| 8 | 声源定位与轨迹跟踪 | 扩展数据图4 |

第7部视频提供等值面和切片两种展示方式。交互查看器涵盖观测中断、尾流、三维声场、声源跟踪与候选证据。

离线使用MeshRIR交互页面时，保留同目录中的`meshrir_isosurface_data/`文件夹；尾流交互页面需要`viv_piv_data/`文件夹。
